Describe what you want in chat. The agent builds or edits the tool for you and shows you the result.

## Two ways to start

**From the New page**

1. Open the New page. **Build with agent** is already selected.
2. Give the tool a **Title** if you like. In **What should it do?**, describe what you want on screen and what the tool should remember between visits.
3. Choose **Start building**. Your answers become the first message on the agent page.

**From an existing tool**

1. Open the tool and choose **More actions**, then **Edit with agent**.
2. On the agent page, the agent reads the tool before it makes changes.

The header says **Agent** and has a **Back** link. If the agent needs your own key, you'll also see **API key**.

## Picking which exhibit it works on

The agent works on one tool at a time.

- When you choose **Start building** or **Edit with agent**, the chat and preview are already tied to that tool.
- The **Preview** bar shows the tool's name. Choose **View artifact** to open the finished tool, or **Open** (**Preview only** for connected tools) to open it in a new tab.
- Check the preview title before sending another request. The agent's changes apply to the tool named there.

## What it can do for you

You can ask the agent to:

- Build a tool from your description.
- Change or fix a tool you've already saved.
- Draft or update the card widget.
- Read the tool's source and explain what it does.

Type your request in **Describe what you want to build or change…**. Use the paper-plane button or press Enter to send it. Press Shift+Enter to start a new line. While the agent works, choose **Stop agent** to interrupt it.

## Following its progress

- **Chat** on the left shows the agent's updates. Chips such as **Creating**, **Writing**, **Editing**, and **Reading** turn into check marks as each step finishes.
- **Preview** on the right shows the live tool. On narrow screens, use the **Chat** and **Preview** tabs to switch between them. If the tool changes while you're reading the chat, **View updated preview** appears above it.

To point the agent to part of the tool, choose **Select an element** above the preview and click the part you want it to look at.

## Looking back at past conversations

1. Choose **History** above the chat. **Previous conversations** shows the newest first, with the last version each conversation worked on and when.
2. Choose a conversation to read it in full. It opens in read-only mode.
3. Choose **Continue this conversation** to pick up where you left off.

If the tool has changed since that conversation, choose how to continue.

- **Restore vN and continue** restores the source and saved data from that version. Exhibit records the restore as a new version and keeps your saved versions in history. Choose **Preview vN** to look first.
- **Continue with current version** keeps the tool as it is and has the agent read it again.

For some older conversations, the card tells you they're available to read only.

## When it asks you a question

If the agent needs a decision from you, it asks in the chat. Use the controls shown with the question.

- Choose an option. Some questions accept more than one.
- Choose **Something else** to write your own answer in **Your answer…**.
- Choose **Done** to confirm your choices when a question accepts several answers.
- Choose **Skip** to move on without answering.

If the questions can't load, choose **Try again** to reload them.
