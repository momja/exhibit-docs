Welcome to the Exhibit docs. Exhibit is a self-hostable personal gallery for
single-file HTML+JS micro-tools ("artifacts"). Each tool runs in a sandboxed
iframe on an isolated origin, with `localStorage` synced through the server so
simple tools share one data state across all your devices.
