Open the New page to add a tool to your gallery. You can describe what you need, paste HTML, or save a page from a URL.

## Pick a starting point

- **Build with agent** is selected when the page opens. Use it to describe the tool you want.
- **Paste HTML** saves HTML you already have.
- **From URL** saves a copy of a web page.

On narrow screens, the buttons read **Agent**, **Paste**, and **URL**. The description of the selected option appears below them.

## Build with agent

1. Give your tool a **Title** if you like.
2. In **What should it do?**, describe what you want to see on screen and what the tool should remember between visits.
3. Choose **Start building**.

The agent uses your description to draft the tool with you. Choose **Cancel** to return to the gallery without creating anything.

## Paste HTML

1. Choose **Paste HTML**.
2. Enter a **Title**, or leave it blank to use "Untitled".
3. Paste your HTML into **HTML source**.
4. Choose **Add to Gallery**.

If you leave **HTML source** empty, the page asks you to paste HTML first.

## From URL

1. Choose **From URL**.
2. Give your tool a **Title** if you like.
3. Enter the full address in **Page URL**, including `http://` or `https://`.
4. Leave the snapshot option on to save the page's files with it. You can turn it off if needed.
5. Choose **Add to Gallery**.

### The snapshot option

**From URL** includes a checkbox labeled **Save images, styles, and scripts with the page (recommended)**. Below it, you'll see "Some files may still require network access."

With the box checked, Exhibit saves copies of the page's images, styles, and scripts with the tool so it can still use those copies if the original files move or disappear. Files Exhibit can't save still point to the original site and may need a connection.

## What happens right after you save

1. Exhibit saves your tool as a new card in the gallery.
2. If the tool needs to contact outside sites, a prompt lists them and asks which ones to allow. Sites stay blocked until you approve them. You can change your choices later.
3. Once saving finishes, the tool opens so you can try it.

If Exhibit can't save everything cleanly, you'll see a message with a link to view what was saved.

You can find the card again in your gallery under the title you entered, or "Untitled".
