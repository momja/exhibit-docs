Get Exhibit running on your machine and save your first artifact in a few minutes.

## Prerequisites

- Go 1.25+
- Node 22+
- `make`
- Pi Bolt (optional) — only needed for agent features

Check your toolchain:

```sh
go version
node --version
make --version
```

## Fastest path: Docker Compose

The quickest way to run Exhibit is with Docker Compose.
See [deployment.md](https://github.com/momja/Exhibit/blob/main/docs/deployment.md)
in the momja/Exhibit repo for the Compose file and environment variables, then:

```sh
docker compose up --build
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

## From source

If you prefer to build it yourself:

```sh
git clone https://github.com/momja/Exhibit.git
cd Exhibit
make build
./bin/server
```

Then open [http://localhost:8080](http://localhost:8080).

## Save your first artifact

Go to `/new` and pick one ingest path:

- **Paste HTML** — drop markup straight into the editor.
- **Upload** — upload an `.html` file or a ZIP bundle.
- **Paste a URL** — paste a link and tick the snapshot option to vendor a copy.

Approve any network origins the page requests when prompted, then open the
saved card from the gallery to use your tool.
