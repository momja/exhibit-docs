Exhibit is a self-hostable personal gallery for single-file HTML+JS micro-tools, where each tool runs in a sandboxed iframe and its `localStorage` syncs through the server so state follows you across devices.

## Key concepts

- **Artifact** — a single self-contained HTML+JS micro-tool, built with the agent, pasted as markup, or saved from a snapshotted URL.
- **Gallery** — the home surface (`/`) listing your artifacts as cards, with Starred, Search, Shared, and Activity views for organizing and rediscovering them.
- **Exhibit tile** — one gallery card: the artifact's title, preview, tags, and actions (open, star, share, edit, version history).
- **Widget** — an optional, read-only HTML preview of an artifact's saved state, rendered inside its gallery card. It reads the same keys the tool writes but cannot write back.
- **Storage shim** — a small preamble injected before artifact scripts that captures `localStorage` writes and syncs them through the server, so reopening a card on another device restores it.
- **Network allowlist / CSP** — each artifact declares the external domains it may call; anything unapproved stays blocked by a per-artifact Content Security Policy.
- **Version history** — changes to artifact and widget source are snapshotted as versions, viewable and restorable from the `#versions-panel` section of `/artifacts/:id/edit`.
- **Sharing links vs grants** — anonymous public links (`/s/:shareID`) let anyone with the URL view the owner's saved state with no write-through, while named grants share with specific signed-in users; either can be revoked so the URL stops resolving.
- **Render surface** — the isolated origin and sandboxed iframe an artifact executes in, separate from the gallery app origin.
- **Agent** — an optional Pi sidecar that can create and edit artifacts through the same HTTP API as the UI.

## Tech stack

- **Go 1.25** server with `html/template` server-rendered pages.
- **SQLite + FTS5** for metadata and full-text search, migrated with `goose`.
- **FS / S3 blobs** for artifact bodies and snapshots.
- **Sandboxed iframe + per-artifact CSP** on an isolated render origin.
- **htmx partials + Stimulus controllers + Phosphor icons** for gallery UI.
- **Pi sidecar** for optional agent-driven authoring.
