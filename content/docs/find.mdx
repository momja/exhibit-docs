Your gallery has four spaces, a search box, and filters. Here is how to move around and keep things tidy.

## The four spaces

The gallery navigation lists these destinations:

- **Starred** — the gallery home. Your starred favorites live here.
- **Search** — the full library with a search box.
- **Shared** — everything shared with you or by you, with a count.
- **Activity** — recent changes and running agents.

## Search

1. Go to **Search**.
2. Type in the **Search** box (keyboard shortcut `/` jumps to it) and press Enter.
3. Use the × control labeled **Clear search** to clear the box.

Search looks through titles, the words shown on the page, and tag names — not the underlying code. If nothing matches, the page says "No artifacts match your search." and suggests trying another title, keyword, or tag.

## Tags and collections

Tags and collections appear as filter sections beside the results:

- **Collections** — named groups of your tools.
- **Tags** — color-dotted labels you attach to tools.

To narrow the gallery:

1. Choose **Filter** to open the **Filters** panel (or use the filter list beside the results on wide screens).
2. Pick a tag or collection. Active filters appear as removable chips above the results.
3. Remove one chip to widen the search, or choose **Clear all** to remove every filter. Choose **Done** to close the panel.

To label a tool, open its edit page and find the **Tags** section — adding or removing a tag there saves immediately, no separate save step.

## Starring

Starring pins a favorite to the **Starred** home page.

1. Open the card's action menu (the three-dots **Actions** button on the card).
2. Choose **Star**. The card gains a star mark.
3. To remove it, open the same menu and choose **Unstar**.

If Starred is empty, the page says "No starred artifacts yet" and points you to the action menu and the Search page.

## The Activity page

Activity shows two things:

- **Running agents** — what is currently building, with a **Refresh** button to update the list. When nothing is running, it says "No agents are running right now."
- **Recent changes** — saved versions and agent changes, each linking out to view the change. Before anything has happened it says no changes exist yet.

## The Shared space

Shared gathers sharing in both directions: tools you shared with others and tools others shared with you. Cards for tools shared with you show the owner's name, and shared tools open view-only — the editing controls belong to the owner.
