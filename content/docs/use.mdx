## Opening a card

Select the card's title or click anywhere on its preview to open the tool. It fills the page inside a preview frame, with a floating toolbar.

- Select the tool's title to open its info card.
- Use the star button to return to **Starred**.
- Use the pencil to open **Edit** if you own the tool.
- Choose **Share** to open sharing if you own the tool.
- Open **More** for extra actions, including opening the tool outside the preview.

You open tools shared with you the same way. Their editing controls are available to the owner.

## Using the tool normally

Click, type, and make changes as you use the tool. Exhibit keeps the entries, settings, and progress the tool saves. If it gets stuck or behaves unexpectedly, reload the page to give it a fresh start. You may lose anything the tool hasn't saved yet.

You may see a banner above the tool.

- If the preview can't give the tool something it needs, the warning explains why and offers **Open in new tab**.
- If something changed elsewhere while you had the tool open, choose **Reload artifact** to use the latest saved data.

## What follows you between devices

To pick up on another device, sign in with the same account and open the same card. Your saved entries and settings follow your account.

If the tool keeps something only in your current tab, closing that tab clears it. That data is only available while the tab is open.

## When a tool asks to connect or download

Exhibit asks before a tool first uses certain features. The prompt names the tool and lets you allow or block the request. Exhibit remembers what you allow for that tool. You can change your choices later under **Edit → Permissions**.

- **Allow network access?** The tool tried to contact the site named in the prompt and was blocked. Choose **Allow site** to allow future requests, **Block once** to block this request, or **Always block site** to block future requests.
- **Allow downloads?** The tool wants to save the named file to your device. Choose **Allow downloads** or **Block**.
- **Allow clipboard access?** The tool wants to use your clipboard. Choose **Allow clipboard** or **Block**.
- **Allow opening links?** You're opening a link to the named site. Choose **Allow links** or **Block**.
- **Allow device access?** The tool wants to use your camera or microphone. Choose **Allow and open** to open the tool in a new tab, where your browser will also ask for permission.
- **Allow location access?** The tool wants to use your location. Choose **Allow and open** to open the tool in a new tab, where your browser will also ask for permission.

Only the owner can allow new sites for a tool shared with you. You'll see a message naming the blocked site.

## Full view

If a tool needs downloads, outside links, or device features, it may work better outside the preview. Choose **Open in new tab** from the **More** menu or from the banner if one appears.

The first time, **Open in a new tab?** explains that the tool will run as a regular web page under your browser's normal controls. Select **Do not ask again for this artifact** if you want to skip the confirmation next time. Choose **Open in new tab** to continue or **Cancel** to stay in the preview.
