Five workflows for day-to-day use of the Exhibit gallery.

## Create and ingest

Start at `/new`, which offers three paths:

- **Build with agent** — describe what you want; the agent drafts the artifact.
- **Paste HTML** — drop markup straight into the editor.
- **From URL** — save a copy of a web page, with an option to snapshot its images, styles, and scripts alongside the page.

URL snapshots can leave live dependencies: files that fail to vendor stay as
live references and still need network access. The artifact is saved first;
when it requests network origins, approval happens after that initial save —
nothing joins the allowlist until you approve it. Your artifact lands as a
gallery card.

Key routes: `/new`, `/`

## Organize and rediscover

- **Starred** (`/`) — the gallery home; pin favorites with Star for one-click access.
- **Search** (`/search`) — full-text search over page content, plus filters for tags and collections.
- **Shared** (`/shared`) — everything shared with you or by you.
- **Activity** (`/activity`) — recent saves, edits, shares, and restores.

Listing pages show 24 cards per page with htmx-powered paging (no full reload).

Key routes: `/`, `/search`, `/shared`, `/activity`

## Use across devices

Open a card on any device and pick up where you left off:

- `localStorage` writes are captured by the storage shim and synced through the state endpoint automatically in supported app-hosted views — no manual step.
- `sessionStorage` stays ephemeral — it never leaves the tab.

Sign in on the second device with the same account and open the same card; synced state loads automatically.

Key routes: `/artifacts/:id`, `/api/artifacts/:id/state`

## Share safely

Two ways to share:

- **Anonymous public links** (`/s/:shareID`) — anyone with the link can view; no account required. The link loads the owner's saved state with no write-through.
- **Named grants** — share with specific signed-in users from the share dialog.

The owner sets the state mode per artifact: **own** (each signed-in grantee
writes their own rows) or **shared** (everyone writes the owner's rows, one
shared board). Revoke a link or grant at any time from the share dialog;
revoked URLs stop resolving.

Key routes: `/s/:shareID`, `/shared`

## Maintain over time

Keep artifacts healthy as pages and widgets evolve:

- **Edit** page source and widget settings at `/artifacts/:id/edit`.
- **Origins** — review and prune approved network origins.
- **State inspector** — inspect persisted state and clear bad values.
- **Versions** — the `#versions-panel` section of the edit page lists snapshots of artifact and widget source; restore one as current.
- **Duplicate / Delete / Export** — clone an artifact, remove it, or export it: self-contained HTML (`GET /api/artifacts/:id/export`, assets folded back in), an assets ZIP (`GET /api/artifacts/:id/assets/export`), or saved-state JSON via the state endpoint.

Key routes: `/artifacts/:id/edit`, `/api/artifacts/:id/versions`, `/api/artifacts/:id/export`
