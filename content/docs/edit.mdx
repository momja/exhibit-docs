Open the tool and choose **Edit** from **More actions**, the three-dot button in the floating toolbar. You can also use the pencil. On the edit page, you'll find **Save** and **View artifact** in the header.

## What's on the edit page

Open the section you need.

1. **Tags**. Add or remove tags. Changes save immediately.
2. **Permissions.** Choose which sites the tool can reach and which features ask first.
3. **Saved data.** See and change what the tool has saved for you.
4. **Stored assets.** See the files saved with the tool so it can load even if the original site changes.
5. **Artifact source.** Edit the tool's page. This section opens by default.
6. **Card widget.** Change the read-only preview on the tool's card. The heading shows **default** until you write your own.
7. **Versions.** View or restore saved changes.

## Edit and save

1. Change **Artifact title**, **Artifact source**, or both.
2. Make any other changes you need in the other sections.
3. Choose **Save** in the header. The status beside the button confirms when your changes are saved.
4. If you try to leave with unsaved edits, **Save changes before leaving?** offers **Keep editing**, **Discard changes**, or **Save and leave**.

**Save** applies to the title and source. Tags save immediately. Use the buttons in **Saved data**, **Stored assets**, and **Card widget** to make changes there.

## Control which sites a tool may reach

Open **Permissions**. You'll find sites on the left and features on the right.

To allow a site:

1. Enter its address in **Site to allow**, for example `https://example.com`.
2. Choose **Add**.

The lists update as you make changes.

- **Allowed sites** lists sites the tool may contact. Choose **Remove** to take a site off the list.
- **Found in source, not allowed** lists sites mentioned in the source that still need approval. Choose **Allow** to approve a site.
- **Blocked** lists sites you've chosen to block without future prompts. Choose **Ask again** to let the tool ask next time or **Allow** to approve the site now.

For **Downloads**, **Clipboard**, **External links**, **Camera**, **Microphone**, and **Location**, choose **Ask first** or **Always allow**. The tool asks before using any feature set to **Ask first**.

## Saved data, assets, and the card widget

In **Saved data**, add keys or change values, then choose **Save data**. Use **Discard data edits** to clear unsaved changes or **Erase current data** to clear all stored data. **Export data (JSON)** downloads a copy you can keep or share. **Import data (JSON)** replaces your stored data with the file you choose.

In **Stored assets**, choose **Export assets (ZIP)** to download the files and a list of where they came from. **Import assets (ZIP)** replaces them with files from the ZIP you choose. Deleting a file is permanent, so check its URL in the source first.

In **Card widget**, write and save your own widget markup, or choose **Generate widget** to have one drafted for you. If you already have a widget, use **Regenerate** to draft another. Choose **Remove** to return to the default widget.

## Versions and restore

Open **Versions** to see every saved version, newest first. The version in use is marked **Current**. Older versions have **View** and **Restore** buttons.

1. Choose **View** to open a preview above the list. The preview runs that version with the data it had at the time. **Viewing vN** appears in the bar, along with a reminder that changes in the preview are temporary.
2. Choose **Back to current** to close the preview or **Restore vN** to restore the version.
3. When you restore a version, Exhibit saves its contents as a new version. The version you were using stays in your history.

## Duplicate, delete, and take a copy

- **Duplicate.** Choose **Duplicate** from the card's action menu to open **Duplicate artifact**. Give the copy a **Title**. Select **Copy sharing settings** to give the same people access and generate a fresh public link if the original had one. Select **Copy saved data** to carry over your results. Choose **Duplicate artifact** to finish.
- **Delete.** Choose **Delete** at the bottom of the edit page. After you confirm, Exhibit permanently removes the tool, its versions, its saved data, and its share links.
- **Download HTML.** In **More actions**, use **Download HTML** to download the tool and its assets in one file. Saved data and account access stay in Exhibit.
- **Update from source.** If you saved the tool from a URL, choose **Update from source** in **More actions** to save it again from its original address.
